📞 如何使用
═══════════════════════════════════════════════════════════════════════════

1. 编译:
   go build -o gofs ./cmd/gofs

2. 启动服务器:
   ./gofs --allow-anonymous-admin -b 127.0.0.1 -p 5000 ./data

3. 运行集成测试:
   chmod +x integration_test.sh
   ./integration_test.sh

4. 测试 API:
   curl -X POST http://127.0.0.1:5000/fs/settings/public-dirs/validate \
     -H "Content-Type: application/json" \
     -d '{"paths":["/"]}'
