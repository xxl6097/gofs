# 广垦南药对接接口文档

> 本平台作为**外部系统侧**（种植管理 / 组培苗管理）对广垦南药主平台开放的接口。
> 严格按照整合《接口鉴权标准文档@20260813》与《茂名农垦南药产业数字化提升平台外部系统对接文档》输出以下文档，
> 统一返回结构、鉴权方式见下文公共说明。

---

## 一、公共说明（ip:http://43.139.151.47:38090）

### 1.1 统一返回结构

所有接口返回 JSON，结构一致：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 返回码，`0000` 为成功，其余为失败 |
| msg  | String | 返回码对应的中文说明 |
| data | Object | 业务数据，失败时为 `null` |

示例：

```json
{
  "code": "0000",
  "msg": "成功",
  "data": { }
}
```

### 1.2 返回码一览

| code | msg | 说明 |
|------|-----|------|
| 0000 | 成功 | 请求成功 |
| 1001 | IP 不在白名单 | 来源 IP 未在白名单内（白名单为空时不校验 IP）|
| 1002 | APP 秘钥校验失败 | 请求头 `appSecretKey` 缺失或不匹配 |
| 1003 | 手机号无效或无该外部系统账号 | 手机号为空，或系统内无该启用账号 |
| 1004 | Token 无效或已过期 | 请求头 `token` 缺失、无效或已过期 |
| 1005 | slat 无效或已过期 | authLogin 的 slat 为空、非数字，或时间戳与服务器时间差超过 60 秒 |
| 5000 | 外部系统内部异常 | 服务端异常 |

### 1.3 鉴权方式

- **授权登录接口**（authLogin）：IP 白名单 + 请求头 `appSecretKey` + 请求体手机号三要素校验。
- **三个业务查询接口**：IP 白名单 + 请求头 `token`。token 由授权登录接口签发，有效期默认 7200 秒。

| 请求头 | 适用接口 | 说明 |
|--------|----------|------|
| appSecretKey | authLogin | 平台分配的 APP 秘钥，**区分大小写** |
| token | 三个查询接口 | 授权登录返回的访问令牌，**区分大小写** |

### 1.4 日期参数说明

查询接口的 `startDate` / `endDate` 支持两种格式：

- 仅日期 `yyyy-MM-dd`：系统自动补全，起始补 `00:00:00`，截止补 `23:59:59`。
- 完整时间 `yyyy-MM-dd HH:mm:ss`：原样使用。

## 二、授权登录 / 单点登录

**接口地址**：`POST {{ip}}/v4/web/agriculture/gkny/authLogin`
**Content-Type**：`application/json`

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| appSecretKey | 是 | 平台分配的 APP 秘钥 |

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | String | 是 | 当前登录用户手机号 |
| slat | String | 是 | 毫秒时间戳，用于生成 token 并做时效校验：`token = md5(sysSecretKey + "@" + slat)`。与服务器时间差须在 60 秒内，否则返回 1005 |

请求示例：

```json
{
  "phone": "13800138000",
  "slat": "1728700000000"
}
```

### 返回 data

| 字段 | 类型 | 说明 |
|------|------|------|
| token | String | 访问令牌，后续查询接口携带 |
| expiresIn | Integer | 有效期（秒），默认 7200 |

返回示例：

```json
{
  "code": "0000",
  "msg": "成功",
  "data": {
    "token": "A1B2C3D4E5F6...",
    "expiresIn": 7200
  }
}
```

### 失败返回

- IP 不在白名单：`1001`
- APP 秘钥校验失败：`1002`
- slat 无效或已过期：`1005`
- 手机号为空 / 无该账号：`1003`

## 三、农事作业实时查询

**接口地址**：`GET {{ip}}/v4/web/agriculture/gkny/queryFarmRecentJobs`
不传 `startDate` / `endDate` 时，返回最近 3 次农事作业记录。

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| token | 是 | 访问令牌 |

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| baseName | String | 否 | 基地名称，不传查整个公司 |
| startDate | String | 否 | 起始日期，如 `2026-09-01` |
| endDate | String | 否 | 截止日期，如 `2026-09-15` |

### 返回 data（数组）

每个元素字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| jobName | String | 作业名称（农事分类-农事操作）|
| jobPeriod | String | 作业时段（实际开始 ~ 实际完成）|
| jobArea | String | 作业区域（地块 / 灌区）|
| materials | String[] | 使用物资列表，元素格式：`物资名 规格*数量` |
| recorder | String | 记录人 |
| photoList | String[] | 作业照片 URL 列表 |

返回示例：

```json
{
  "code": "0000",
  "msg": "成功",
  "data": [
    {
      "jobName": "施肥-追肥",
      "jobPeriod": "2026年09月01日 ~ 2026年09月01日",
      "jobArea": "A区1号地块",
      "materials": ["尿素 40kg*2", "复合肥 25kg*3"],
      "recorder": "张三",
      "photoList": ["https://xxx/a.jpg", "https://xxx/b.jpg"]
    }
  ]
}
```

### 失败返回

- IP 不在白名单：`1001`
- token 无效或过期：`1004`

## 四、农事作业次数统计（1~12 月份）

**接口地址**：`GET {{ip}}/v4/web/agriculture/gkny/queryFarmJobCount`
按年统计每月**已完成且已审核**的农事作业次数，固定返回 12 个月完整数组。

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| token | 是 | 访问令牌 |

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| baseName | String | 否 | 基地名称，不传统计整个公司 |
| year | String | 否 | 年份，如 `2026`，不传统计今年 |

### 返回 data（固定 12 个元素）

| 字段 | 类型 | 说明 |
|------|------|------|
| month | Integer | 月份 1~12 |
| jobCount | Long | 当月作业次数，无数据为 0 |

返回示例：

```json
{
  "code": "0000",
  "msg": "成功",
  "data": [
    { "month": 1, "jobCount": 0 },
    { "month": 2, "jobCount": 3 },
    { "month": 3, "jobCount": 5 },
    { "month": 4, "jobCount": 0 },
    { "month": 5, "jobCount": 0 },
    { "month": 6, "jobCount": 0 },
    { "month": 7, "jobCount": 0 },
    { "month": 8, "jobCount": 0 },
    { "month": 9, "jobCount": 0 },
    { "month": 10, "jobCount": 0 },
    { "month": 11, "jobCount": 0 },
```

### 失败返回

## 五、育苗数据统计

**接口地址**：`GET {{ip}}/v4/web/agriculture/gkny/querySeedlingCount`
按时间区间统计组培苗育苗数据。

### 请求头

| 名称 | 必填 | 说明 |
|------|------|------|
| token | 是 | 访问令牌 |

### 请求参数（Query）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | String | 否 | 起始日期，如 `2026-09-01` |
| endDate | String | 否 | 截止日期，如 `2026-09-15` |

### 返回 data

| 字段 | 类型 | 说明 |
|------|------|------|
| batchNum | Integer | 育苗批次数（接种记录条数）|
| totalSeedlingNum | Long | 育苗总株数（接种株数合计）|
| pollutionNum | Long | 污染株数（筛选污染数合计）|
| transplantNum | Long | 移栽株数（总株数 - 污染株数）|

返回示例：

```json
{
  "code": "0000",
  "msg": "成功",
  "data": {
    "batchNum": 12,
    "totalSeedlingNum": 36000,
    "pollutionNum": 1200,
    "transplantNum": 34800
  }
}
```

### 失败返回

- IP 不在白名单：`1001`
- token 无效或过期：`1004`
